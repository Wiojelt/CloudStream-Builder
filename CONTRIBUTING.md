# Katkıda bulunma

CloudStream Builder her türlü desteğe açıktır. Hata bildirirken mümkünse hedef URL'yi, beklenen sonucu, oluşan hatayı ve gizli bilgi içermeyen ilgili log bölümünü paylaşın.

Kod katkıları için:

1. Depoyu fork edin ve değişikliği ayrı bir dalda hazırlayın.
2. Beceri yapısını doğrulayın:

   ```powershell
   python C:\Users\root\.codex\skills\.system\skill-creator\scripts\quick_validate.py .\cloudstream-builder
   ```

3. Denetim aracını örnek bir TurkStream Studio işi üzerinde çalıştırın.
4. Değişikliğin hangi gerçek sorunu çözdüğünü pull request açıklamasında belirtin.

Kişisel çerez, token, parola, sertifika, korsan medya bağlantısı veya cihaz verisi göndermeyin.
